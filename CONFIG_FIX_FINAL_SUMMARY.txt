================================================================================
                      PYDANTIC V2 MIGRATION
================================================================================

What Changed:

Old Way (Config class):
  class Settings(BaseSettings):
      class Config:
          env_file = ".env"
          case_sensitive = False

New Way (model_config):
  class Settings(BaseSettings):
      model_config = ConfigDict(
          env_file=".env",
          case_sensitive=False,
          extra="ignore"
      )

Benefits:
  - Simpler, more explicit
  - Better IDE support
  - Future-proof (Pydantic v2 is actively developed)
  - Easier to extend with more options

The Key Addition: extra="ignore"
  - Purpose: Don't error on unknown environment variables
  - Effect: UNKNOWN_VAR=value in .env won't cause validation error
  - Use case: CI/CD systems often inject extra variables

  CORS_ORIGINS (default: localhost:3000)

  - Allows CI/CD flexibility
