Claude cites specific clauses and sections:

### 4️⃣ **Smart Follow-up Suggestions**
Claude suggests related questions automatically:
- `follow_up_questions[]` array with 2-3 related questions
- Displayed as clickable buttons below each response
- Helps users explore document in natural conversation flow
- Reduces cognitive load of thinking up next question

**Backend:** `/api/v1/chat` endpoint response

```typescript
// After answering "Can I delete my account?", suggest:
follow_up_questions: [
  "How long does account deletion take?",
  "Can I download my data before deletion?",
  "Is deletion permanent?"

```

### 5️⃣ **FAQ Generation from Analysis**
Generates FAQs on-demand using the initial analysis:
- Runs immediately after document scan completes
- Uses executive_summary + key_risks from analysis
- Falls back to smart defaults if generation fails
- No additional user clicks needed

**Process:**
```
Document Scanned
    ↓
Analysis Complete
    ↓
Auto-trigger FAQ Generation
    ↓
3-5 FAQs displayed instantly
```

### 6️⃣ **Full Backend Integration**
Two new REST endpoints for Q&A:

#### POST `/api/v1/generate-faqs`
Generate FAQ questions
```json
Request:
{
  "document_content": "Full document text...",
  "doc_type": "privacy",
  "summary": {
    "executive_summary": "...",
    "key_risks": ["..."]
  }
}

Response:
{
  "suggested_faqs": [
    "Do they sell my data?",
    "How do I opt out?",
    "..."
  ]
}
```

#### POST `/api/v1/chat`
Answer follow-up questions
```json
Request:
{
  "content_hash": "abc123...",
  "question": "Can I delete my account?",
  "document_context": "Section of document..."
}

Response:
{
  "answer": "Yes, you can delete your account by...",
  "sources": ["Section 4.2: Account Deletion"],
  "follow_up_questions": [
    "How long does it take?"
  ]
}
```

## Data Flow

### FAQ Generation Flow
```
DocumentSummary loads
    ↓
contentHash, documentContent, docType passed to QuestionAnswerSection
    ↓
useEffect triggers on mount
    ↓
Calls generateFAQs API
    ↓
Backend calls claude_client.generate_faqs()
    ↓
Claude analyzes summary + risks
    ↓
Returns 3-5 contextual questions
    ↓
FAQs displayed as clickable chips
```

### Chat Flow
```
User clicks FAQ or types custom question
    ↓
Question added to chatHistory as 'user' message
    ↓
Calls chatWithDocument API
    ↓
Backend retrieves cached analysis
    ↓
Calls claude_client.answer_follow_up()
    ↓
Claude answers using analysis + context
    ↓
Returns answer + sources + follow-ups
    ↓
Assistant message added to chatHistory
    ↓
User can click follow-up suggestions
```

## Code Examples

### Example 1: FAQ Generation
```typescript
// In QuestionAnswerSection.tsx
const loadSuggestedFAQs = async () => {
  const response = await fetch('/api/v1/generate-faqs', {
    method: 'POST',
    body: JSON.stringify({
      document_content: documentContent,
      doc_type: docType,
      summary: summary,
    }),
  });
  const data = await response.json();
  setFaqs(data.suggested_faqs);
};
```

### Example 2: Chat Submission
```typescript
// User clicks "Ask" button
const sendQuestion = async (question: string) => {
  setChatHistory(prev => [...prev, { role: 'user', text: question }]);
  
  const response = await fetch('/api/v1/chat', {
    method: 'POST',
    body: JSON.stringify({
      content_hash: contentHash,
      question: question,
      document_context: documentContent,
    }),
  });
  const data = await response.json();
  
  setChatHistory(prev => [...prev, {
    role: 'assistant',
    text: data.answer,
    sources: data.sources,
    followUps: data.follow_up_questions,
  }]);
};
```

### Example 3: Claude FAQ Generation
```python
# In claude_client.py
async def generate_faqs(self, document_text, doc_type, analysis):
    prompt = f"""Generate 3-5 contextual FAQ questions
    
Summary: {analysis['executive_summary']}
Risks: {', '.join(analysis['key_risks'])}

Return ONLY JSON array of strings."""
    
    message = self.client.messages.create(
        model=self.model,
        max_tokens=500,
        messages=[{"role": "user", "content": prompt}]
    )
    
    return json.loads(message.content[0].text)
```

## Error Handling

### FAQ Generation Errors
```
API Error → Display "Failed to load FAQ suggestions"
         → Use smart defaults (always available)
         → User can still ask custom questions
```

### Chat Errors
```
API Error → Display "Failed to get answer. Please try again."
         → Remove pending user message
         → Preserve chat history
         → Allow retry
```

### Network Errors
```
Timeout → Show error message
       → Suggest retry
       → User questions preserved
```
