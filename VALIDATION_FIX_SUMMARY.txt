================================================================================
                      DETECTION LOGIC (NEW)
================================================================================

Priority Order:
  1. URL Pattern Matching   → Check for /privacy, /terms, /cookie, etc.
  2. Page Title Analysis    → Look for "Privacy Policy", "Terms of Service", etc.
  3. Heading Analysis       → Scan <h1>, <h2>, <h3> for legal keywords
  4. Fallback Default       → Use "privacy" (safest and most common)

Examples:
  https://example.com/privacy-policy        → Detects "privacy"
  https://example.com/terms-of-service      → Detects "tos"
  https://example.com/cookie-policy         → Detects "cookie"
  https://example.com/eula                  → Detects "eula"
  https://example.com/api/terms             → Detects "api_terms"
  https://example.com/legal-stuff           → Falls back to "privacy"
